# Commander deck library - Tabletop Simulator assets

Card sheets and saved objects generated by the custom Commander deck library (`common/export.py --publish`). Each `*.json` is a Tabletop Simulator saved object: drop it into `Documents/My Games/Tabletop Simulator/Saves/Saved Objects/` to play that deck. Sheet images are named by content hash so a re-export never serves a stale cached sheet.
